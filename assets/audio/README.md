# مجلد الصوتيات

هذا المجلد مخصص لملفات MP3 المحلية للأذكار.

حاليًا يحمّل مشغّل الموقع التسجيلات من مصادرها المنشورة في ملف `data/adhkar.json`:
- تلاوات القرآن: EveryAyah – رواية حفص بصوت مشاري العفاسي.
- الأدعية: تسجيلات حصن المسلم المنشورة على hisnmuslim.com.

لإضافة نسخة محلية لاحقًا، ضع ملف MP3 هنا ثم غيّر قيمة `audio.src` أو عناصر `audio.sources` في ملف JSON إلى المسار النسبي، مثل:
`assets/audio/bismillah-protection.mp3`

لا تنسب التسجيلات إلى الموقع ولا تعِد نشرها خارج شروط الجهة الناشرة.
