# مكتبة الصوتيات المحلية

تُحفظ التسجيلات المستخدمة في التطبيق داخل هذا المجلد، ويشير ملف `data/adhkar.json` إلى المسارات المحلية مباشرة.

## القرّاء والمصادر

- أذكار الصباح والمساء: تسجيلات حمد الدريهم.
- آية الكرسي وآخر آيتين من البقرة وسور الإخلاص والفلق والناس: مشاري راشد العفاسي.

## طريقة التشغيل

تُنسخ الملفات إلى حزمة الويب عند البناء، لذلك تعمل داخل التطبيق دون الحاجة إلى الاتصال بموقع صوتي خارجي. في أول تنزيل لحزمة التحديث تُنزّل ملفات الصوت معها، وبعد ذلك تعمل دون اتصال.

لا تُغيّر أسماء الملفات دون تحديث المسارات في `data/adhkar.json`.
